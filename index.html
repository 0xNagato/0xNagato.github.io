A

A multi-agent AI assistant my family talks to on WhatsApp

I run a self-hosted multi-agent system built on OpenClaw. Each family member has their own agent, with its own memory and workspace, and reaches it on the messaging app they already use. A separate team of four agents (coordinator, researcher, reviewer and writer) handles research work.

When one AI provider hits a rate limit, the system moves to the next one, and a plugin I wrote queues the reply and retries it so no message is lost.

B

Open-source tools that make AI agents more reliable

AI agents fail quietly. A search tool returns the first 50 results and the agent decides nothing else exists. A skill never runs because its description does not say when to use it. I build small tools that close those gaps. All four are MIT licensed.

ctxgrep
Code search that fits a token budget, ranks definitions first, and reports how many matches it left out. Rust, runs as a command and as an MCP server.
skill-lint
Finds agent skills and tool definitions that will never get picked, and tools that can do damage without asking first. Python, no dependencies.
logdex
Indexes logs too large to open and returns pointers to the lines that matter. A 127 MB log became a 1.1 MB index in 4.4 seconds.
confound-check
A review procedure for agents. Before a claim that one thing caused another is accepted, every rival explanation gets a check that can be run.
C

A real-time trading system in Rust, built with AI agents under written rules

A private system that trades five-minute Bitcoin prediction markets. It streams prices and order books, evaluates a model on the newest state, and places orders. Paper trading runs beside live trading, so every change is compared before it is trusted with money.

I built it with AI coding agents. The part I would show you is the control around them: a written operating contract, hooks that block unsafe actions, tests on data the model has not seen, and an append-only log of every result. Most strategies I test do not survive fees, and the log of what failed is the most useful thing in the repository.
